# Changelog

The newest version first. The release workflow publishes the section of a
version as its release notes: keep the `## <version> (<date>)` heading.

## 0.1.0 (2026-11-11)

The first release.

- See every systemd user timer in one window: when it runs next, in words, and
  how its last ten runs went.
- Read the log of a timer and of its task, live, with only the problems if you
  want.
- Drop a script or a program on the window to make a timer from it: Tempo reads
  it without running it and says what to fix first.
- Choose when it runs and under which conditions, see the next runs and try the
  command once before saving.
- Get a desktop notification when a run fails, even when Tempo is closed.
- Run, pause, turn off, edit and delete the timers Tempo made; delete can be
  undone. Timers of the system are shown read-only, with the commands to stop
  them.
- English and French, light and dark.
